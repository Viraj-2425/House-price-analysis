Bengaluru House Price Analysis
Overview

This project analyzes Bengaluru house price data using Python and Data Analytics techniques. The objective is to explore housing trends, clean the dataset, perform exploratory data analysis (EDA), and extract meaningful insights from the data.

Dataset

The dataset contains information about house prices in Bengaluru, including:

Location
Size (BHK)
Total Square Feet
Number of Bathrooms
Price
